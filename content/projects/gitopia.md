Gitopia is a 2D space adventure that teaches Git through gameplay. Players are stranded in space and must use real Git commands to get home: committing progress, branching to explore planets, and merging to fix their ship. Puzzles run through a terminal style interface, so the mechanics map directly to commands you would type in a real terminal.

Built with React and Phaser.js for the game, Express for the backend, and MongoDB to track player progress and leaderboards.
